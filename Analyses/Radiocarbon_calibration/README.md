# Calibration of Fossil936 14C date
Here we provide the R code used to calibrate the conventional radiocarbon date (14C) of Fossil936.
 - `Fossil936_14C.R`. Author: Nicoholas A. Freymueller.

Note that this code is also available in Supplementary Data S4 on Zenodo as part of the ecological niche modelling pipeline: https://doi.org/10.5281/zenodo.18865979. 
 - Specifically, it is in the `WildebeestOccPrep.R` script, where the other radiocarbon dates associated with fossil wildebeest occurrences (Table S15 in the manuscript) are also calibrated.
