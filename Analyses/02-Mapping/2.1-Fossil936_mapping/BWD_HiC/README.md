# Competitive mapping of aDNA data
Competitively map the Fossil936 and simulated SRR27955277_damaged reads to the wildebeest BWD-HiC nuclear genome, Fossil936 mitogenome, human mitogenome, and human nuclear genome.

- The `Wildebeest_*_compMap_BWD_HiC.slurm` files submit jobs that run paleomix with the settings in the `.yaml` files.
