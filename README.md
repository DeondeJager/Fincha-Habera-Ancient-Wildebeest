# Fincha-Habera-Ancient-Wildebeest
Code for the analyses and figures of the paper on the ancient wildebeest genome (Fossil936) from Fincha Habera, entitled **42,000-year old bovid tooth from high-elevation Ethiopia reveals lost African megafauna diversity**.

See the individual `Analyses` subfolders for more detailed information provided by READMEs in those folders.

As a general rule, the `Figures` subfolders do not contain READMEs with additional information, as there is generally just one script with its corresponding input files.
 - The exception is `Figures/Fig1E-Elevation_sampling_sites`, which contains a README describing how to extract the elevation of localities/sites with GPS coordinates from a digital elevation model in QGIS.
